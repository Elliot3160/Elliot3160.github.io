How It Works (Super Simple)

You don’t need any coding experience. Just follow these steps:

1. Install Visual Studio Code (free)
   https://code.visualstudio.com

2. Download the website template (ZIP) from this page.

3. Extract the ZIP and open the folder.

4. Open Visual Studio Code.

5. Inside VS Code:
   - Click File → Open Folder → select the template folder
   - Make sure two files exist (or create them):
        index.html
        style.css

6. Open index.html and replace the placeholder text with your own
   (your name, your bio, your sections, etc.)

7. Open style.css if you'd like to change colours, fonts or spacing
   (optional — beginners can ignore this)

8. Make a GitHub account (free)

9. Create a new repository named:
   yourusername.github.io

10. Upload index.html and style.css to the repo.

11. Wait 1–2 minutes, then visit:
    https://yourusername.github.io

Boom — your website is live worldwide.
