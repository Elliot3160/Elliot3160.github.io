What Machine Learning Revealed About Tephra Classification

A technical insight into how ensemble classifiers behave on volcanic geochemical datasets and what this reveals about feature separability in Earth systems.

Technical insight Tephra geochemistry Ensemble learning Compositional data By Elliot May

Core insight

Ensemble machine learning applied to tephra geochemistry shows that predictive uncertainty is primarily controlled by overlap in feature space between volcanic sources. Algorithm choice influences stability, but does not override the constraints imposed by the underlying geochemical distributions.

Background Key patterns Probability structure Feature overlap Compositional effects

Background and study context

Tephra deposits preserve geochemical signatures used to infer volcanic source regions and correlate stratigraphic units. However, distinguishing between sources is often non-trivial because multiple volcanic systems can produce chemically similar deposits, particularly in major oxide and trace element space. This results in partially overlapping class distributions rather than clearly separable categories.

Traditional correlation approaches rely on expert interpretation of geochemical similarity alongside stratigraphic context. While effective, these approaches become less stable when dealing with high-dimensional datasets or chemically similar volcanic systems.

Statistical learning methods provide a framework for modelling class membership probabilistically based on observed geochemical feature distributions. In this setting, the goal is not deterministic classification, but estimation of separability within feature space.

Scope

This analysis focuses on how supervised learning models behave on compositional tephra data, particularly in regions of overlapping geochemical structure and limited class separability.

Key predictive patterns

Across ensemble models, prediction confidence was strongly structured by feature space geometry. Well-separated volcanic sources produced stable, high-confidence predictions, while overlapping geochemical regions produced distributed probability outputs.

These patterns were consistent across Random Forest, XGBoost, and Flexible Discriminant Analysis (FDA), indicating that uncertainty is primarily driven by data structure rather than model selection.

Probability structure in ensemble models

Combining models through probability averaging reduced variance in predictions and reduced extreme confidence assignments. However, ensemble outputs still reflected multi-modal probability distributions in regions of strong class overlap.

This indicates that ensemble methods stabilise predictions but do not remove ambiguity inherent in the feature space.

Geochemical overlap as the primary constraint

Misclassification patterns were consistently associated with overlap in geochemical signatures between volcanic sources.

This overlap arises due to:

Similar magma chemistryDifferent volcanic systems producing comparable oxide signatures.
Post-depositional alterationModification of original geochemical signals after deposition.
Limited separabilityIntrinsic similarity between some volcanic sources in measured feature space.

These constraints define an upper limit on classification performance independent of model complexity.

Effect of compositional data treatment

Centred log-ratio (CLR) transformation was used to account for the compositional nature of geochemical data.

CLR improved representation of variance structure in some cases, particularly where closure effects distorted feature relationships. However, its impact was variable across classes, indicating that transformation cannot resolve fundamental overlap between similar geochemical populations.

Overall, results indicate that tephra classification performance is primarily limited by feature space structure rather than model selection.

Machine learning provides a quantitative framework for identifying where geochemical similarity constrains predictive separability.
